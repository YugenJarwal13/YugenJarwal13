## Featured Projects

### 🌊 NetSurf - Agentic AI Browser *(Private · Research)*
> Electron · React · TypeScript · Zustand · Multi-LLM (GPT-4o, Claude, Gemini)

A fully functional Chrome-alternative desktop browser with an LLM reasoning loop embedded *inside* the browser process — no cloud daemon, no extension sandbox. Achieved **76% task success rate** on WebArena (+24pts over Playwright baseline) and **100/100 ad-blocking score**, outperforming Brave.

**Co-authored research paper** on the Intent-in-the-Loop paradigm. Source code is private; browser is publicly downloadable.

[🌐 Website & Download](https://net-surf.vercel.app/) · [📄 Showcase Repo](https://github.com/YugenJarwal13/NetSurf)

### 🚗 Wrong-Way Vehicle Detection
> YOLOv10m · OpenCV · Kalman SORT · Hungarian Algorithm · Scikit-learn

End-to-end highway surveillance pipeline. **100% precision (zero false alarms)** on 1,718 frames of normal traffic. Achieved mAP@0.5 of 87–97% with real-time GPU inference at ~30 FPS on 1280×720 video. 7-condition zone-sequence validation engine with motion vector alignment.

[📂 Repo](https://github.com/YugenJarwal13/Wrong-Way-Vehicle-Detection)

### ⚖️ Legal Dark Pattern Detector
> Mistral-7B · QLoRA Fine-Tuning · RAG · ChromaDB · Groq API · Streamlit

Detects predatory clauses in Terms of Service documents using a **5-model hybrid inference architecture** (Mistral base, Mistral fine-tuned, Groq zero-shot, Groq few-shot, Groq RAG). RAG pipeline grounded in GDPR articles achieved **zero hallucinations**. Streamlit dashboard for side-by-side model comparison.

[📂 Repo](https://github.com/YugenJarwal13/Legal-Dark-Pattern-Detector)

### 🇮🇳 India Tourism Perception Analysis
> VADER · HuggingFace Transformers · ABSA · pytrends · YouTube Data API v3

Research-grade NLP study across **6 Indian states** using Aspect-Based Sentiment Analysis on YouTube comments. Key finding: **influencers drive 6.1× more engagement** than official DMOs (Chi-squared: χ²=223.43, p<0.001). Cross-validated with Google Trends and Ministry of Tourism footfall data via Spearman correlation.
